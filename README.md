# Configuração de uma Instância de Banco de Dados no Microsoft Azure

## Descrição

Este repositório foi criado como parte do desafio da DIO com o objetivo de praticar a configuração de uma instância de Banco de Dados na plataforma Microsoft Azure.

---

## Objetivos

- Aplicar conceitos de computação em nuvem.
- Criar e configurar uma instância de banco de dados no Azure.
- Documentar o processo realizado.
- Utilizar o GitHub como ferramenta de documentação técnica.

---

## Tecnologias Utilizadas

- Microsoft Azure
- Azure SQL Database
- Git e GitHub

---

## Passo a Passo da Configuração

### 1. Acesso ao Portal Azure

Acessei o portal do Azure utilizando minha conta Microsoft.

### 2. Criação do Banco de Dados

- Naveguei até **SQL Databases**.
- Cliquei em **Create**.
- Escolhi a assinatura e o grupo de recursos.
- Defini o nome do banco de dados.
- Criei um novo servidor SQL.

### 3. Configuração do Servidor

- Nome do servidor.
- Região de hospedagem.
- Usuário administrador.
- Senha de acesso.

### 4. Configuração de Rede

- Liberação do IP para acesso externo.
- Definição das regras de firewall.

### 5. Revisão e Implantação

- Revisão das configurações.
- Implantação do recurso.
- Verificação da conclusão da implantação.

---

## Aprendizados

Durante o laboratório foi possível compreender:

- Conceitos de **Banco de Dados como Serviço (DBaaS)**.
- Organização de recursos através de **Resource Groups**.
- Importância das configurações de **segurança e firewall**.
- Processo de **provisionamento de serviços** no Azure.

---

## Dicas e Boas Práticas

- Utilizar nomes padronizados para recursos.
- Revisar custos antes da implantação.
- Remover recursos não utilizados para evitar cobranças.
- Documentar cada etapa do processo.
